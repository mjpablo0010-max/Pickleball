# Quadro Pickleball Website

A responsive, one-page website for Quadro Pickleball, built with plain HTML, CSS, and JavaScript. No build step or package installation is required.

## Files
- `index.html` — page structure and content
- `styles.css` — white-and-blue styling and mobile responsive layout
- `script.js` — mobile navigation and automatic footer year

## Run locally
Open `index.html` in any modern browser.

## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish your site.
